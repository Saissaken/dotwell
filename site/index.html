Your Mac's health,
at a glance.

Dotwell is a tiny, native menu bar app that watches ping, CPU, memory, disk, power and network, and tells you with a single dot whether everything is fine. It barely uses any resources itself.

When everything is fine, the dot is green and the popover stays calm.

Everything you need. Nothing you don't.

One dot tells you

Green, yellow or red in the menu bar, with hysteresis so it never flickers. Look up only when it changes.

Ping comes first

Latency, packet loss and jitter against your router, public DNS and cloud regions, so you know whose fault it is.

The whole picture

CPU, memory pressure, disk, power draw in watts and network throughput, each with a minimal sparkline.

Knows when it's hot

Tells you when macOS slows your Mac down to cool it, and shows the CPU temperature next to the load.

Names the culprit

CPU, memory, disk and battery each show the app using the most, sampled only while the popover is open.

Updates itself

Signed updates download quietly in the background and install the next time it quits.

Lighter than what it measures.

A monitor shouldn't be the thing slowing your Mac down. These are the targets Dotwell is built against, with the popover closed.

No helpers, no subprocesses. Everything is read directly from Mach, IOKit and sysctl, in Swift.

Get Dotwell.

Download

  1. Open Dotwell.dmg and drag Dotwell onto Applications.
  2. The first launch is blocked because the app isn't notarized yet. Allow it once in System Settings → Privacy & Security → Open Anyway.
  3. That's it. Dotwell opens at login and keeps itself up to date.
Download Dotwell.dmg

Homebrew

The repository is its own tap.

brew tap saissaken/dotwell https://github.com/Saissaken/dotwell
brew install --cask dotwell

Or build it yourself with make app. See the README.
